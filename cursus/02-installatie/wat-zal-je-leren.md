## Kernvragen

Dit hoofdstuk gaat over het installeren van Linux in een virtuele omgeving en in de cloud. Je leert wat virtualisatie is, hoe je een VM aanmaakt en hoe je een Ubuntu Server of Desktop installeert.

1. Wat is virtualisatie en waarom gebruiken we het?
2. Hoe maak je een nieuwe virtuele machine aan in VMware Workstation?
3. Hoe installeer je Ubuntu Server in een VM en hoe verbind je via SSH?
4. Hoe installeer je Ubuntu Desktop in een VM en hoe maak je een snapshot?
5. Hoe zet je een Ubuntu Server op in Azure Cloud via de Azure portal?

## Doelstellingen

De student(e)...

1. ... kan uitleggen wat virtualisatie is en het verschil beschrijven tussen een host- en een gast-besturingssysteem.
1. ... kan een nieuwe virtuele machine aanmaken in VMware Workstation met de juiste instellingen (schijfgrootte, UEFI, ISO-bestand).
1. ... kan Ubuntu Server installeren in een VM en de basisinstellingen configureren (toetsenbord, gebruiker, SSH).
1. ... kan via SSH verbinding maken met een lokale of cloudserver.
1. ... kan Ubuntu Desktop installeren in een VM en de eerste login doorlopen.
1. ... kan een snapshot maken van een VM en uitleggen waarvoor dit dient.
1. ... kan een Ubuntu Server aanmaken in Azure Cloud via de Azure portal.
1. ... begrijpt waarom VM-bestanden niet opgeslagen mogen worden in gesynchroniseerde mappen zoals OneDrive of Google Drive.
