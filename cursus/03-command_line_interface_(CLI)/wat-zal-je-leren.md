## Kernvragen

Dit hoofdstuk introduceert de command line interface (CLI) als werkomgeving. Je leert hoe je met het toetsenbord commando's invoert, hoe je hulp vindt via manpages en hoe je de shell history efficiënt gebruikt.

1. Wat is een CLI en waarom wordt het gebruikt in Linux-servers?
2. Hoe zijn commando's opgebouwd (commando, opties, argumenten)?
3. Hoe vind je informatie over een commando via man, whatis en apropos?
4. Hoe gebruik je de shell history om eerder gebruikte commando's terug te vinden en te hergebruiken?
5. Wat is sudo en wanneer heb je het nodig?

## Doelstellingen

De student(e)...

1. ... kan uitleggen wat een CLI is en het verschil beschrijven met een GUI.
1. ... kan inloggen op een Linux-server via de CLI en de prompt herkennen en interpreteren.
1. ... kan de structuur van een Linux-commando uitleggen: commando, opties (beginnend met `-`) en argumenten.
1. ... kan de manpage van een commando openen, doorzoeken en navigeren met de correcte sneltoetsen.
1. ... kan met `man -k` of `apropos` het juiste commando opzoeken op basis van een trefwoord.
1. ... kan `whatis` en `whereis` gebruiken om snel informatie over een commando op te zoeken.
1. ... kan de shell history gebruiken via de pijltjestoetsen, `history`, `!!` en `Ctrl+R`.
1. ... begrijpt wanneer en waarom `sudo` nodig is en kan het correct toepassen.
